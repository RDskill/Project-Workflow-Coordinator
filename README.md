# Project Workflow Coordinator

Référentiel maître pour organiser les projets ChatGPT / Work / Codex / GitHub.

Fichiers :
- `PROJECT_WORKFLOW_COORDINATOR.md` : règles complètes.
- `CHATGPT_CUSTOM_INSTRUCTIONS.md` : version compacte pour ChatGPT.
- `CODEX_GLOBAL_INSTRUCTIONS.md` : version compacte pour Codex.
- `CURRENT_STATE_TEMPLATE.md` : modèle d'état courant par projet.

Principe : CURRENT_STATE fiable → Context Guard → AUDIT → CORRECTION → VALIDATION → Artifact Release Guard.
